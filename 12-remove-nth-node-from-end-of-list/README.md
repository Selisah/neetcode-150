# 12 · Remove Nth Node From End of List (Medium) · Linked List

## The problem
Given the `head` of a linked list, remove the `n`th node from the end of the list and return its head.

## Examples
- `head = [1, 2, 3, 4, 5]`, `n = 2` returns `[1, 2, 3, 5]`
- `head = [1]`, `n = 1` returns `[]`
- `head = [1, 2]`, `n = 1` returns `[1]`

## Constraints
- The number of nodes in the list is `sz`.
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## How to run
```bash
python solution.py
```
